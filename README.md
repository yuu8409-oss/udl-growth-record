# UDL로 함께 성장하는 우리

보편적 학습 설계를 적용한 수업 참여 기록 도구입니다.

이 앱은 UDL 지원을 적용한 수업 장면에서 학생의 참여 흐름을 기록하고 돌아보기 위한 교사용 관찰·성찰 도구입니다. 학생을 평가하거나 진단하기보다, 어떤 수업 지원과 활동 장면에서 참여가 어떻게 나타났는지 살펴보고 다음 수업을 조정하는 데 목적이 있습니다.

## 현재 버전

- v1.4.8 · 수정 92
- 정리 기준: 2026-07-08

## 주요 기능

- 학생 코드 기반 기록 관리
- 날짜, 시간대, 과목 기록
- 수업 활동 태그 선택
- UDL 원리별 지원 전략 선택
- 1~5점 참여 점수 기록
- 선택형 자세한 기록: 수업 참여가 어려웠던 순간, 선행사건, 관찰된 참여 모습, 결과
- 학생별 최근 2주 참여 변화 그래프
- 그래프 점 클릭/터치 시 선택 기록 확인
- UDL 원리별 기록 흐름
- 높은 참여 기록에서 함께 나타난 UDL 지원 확인
- 학생의 강점으로 보인 과목·활동 요약
- 기록 종합 분석 보기
- 학생 등록 및 자료 백업/불러오기
- PWA 설치 지원

## 해석 원칙

이 앱은 학생을 평가하거나 진단하기 위한 도구가 아닙니다. 기록된 참여 점수는 해당 수업 장면에서 관찰된 참여 정도를 나타내는 참고 자료입니다. UDL 지원과 참여 변화 사이의 인과관계를 단정하지 않으며, 과목, 활동 유형, 시간대, 학생 컨디션, 또래 관계, 수업 환경을 함께 고려해 해석해야 합니다.

## GitHub Pages 사용 방법

1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드합니다.
2. 저장소 Settings > Pages에서 배포 브랜치를 선택합니다.
3. index.html이 루트에 있으면 GitHub Pages에서 바로 실행됩니다.

## 개인정보 안내

학생 실명, 장애명, 연락처 등 민감정보는 입력하지 않는 것을 권장합니다. 학생 코드를 사용해 주세요.
